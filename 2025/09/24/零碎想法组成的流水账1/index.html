零碎想法组成的流水账1

发表于 2025-09-24 |
小时候总是被说作文写的很烂。烂到什么程度？一个足球踢来踢去的流水账硬凑300字。事实证明确实很烂，语文成绩就没好过。但是现在用AI让它帮忙润色一下就不会很烂了捏。(其实这篇文字的重点不是这个，上面的内容只是我用来凑描述的)

前言

故事从早上上班想要买一瓶茶喝说起，我走到无人售货机的屏幕前的时候，惊奇地发现屏幕上居然显示”Hello World”。作为一个CS宗的弟子之一，我每次见到这几个字母总会有感觉，有时是不屑，有时是【我懂别人不懂】的装逼感。我决定给这个现象搞一个类比，就像在外历练多年，在不同的地方看到最初修行的【聚气决】，某些机缘巧合下会对修行大道产生不同的感悟。这一次，我的脑海中一下子就出现了一个故事，一个【绝代天骄】（天才黑客）黑掉了宿舍楼下的无人售货机，来炫耀自己的实力。

让我来解释这个故事为什么会在脑海中出现，我会这样解释：

1.理想的种子 在小学玩造梦西游拜师学习【异次元修改】的时候，立志以后要成为一名黑客

2.身处环境 超级大宗门——信息黄泉BUPT，出一个黑客还是有可能的吧

3.喜欢幻想 脑补了字母背后发生的故事、想要从平常的日子中突然掉进神秘事件、想要等发工资然后在币圈回本

4.这一天相比以前有所不同刺激了我的大脑

……

最近在看一本小说叫做《我的模拟长生路》，主角的金手指就是能够无限次带着记忆返回以前的某个时空锚点。作者老是会解释是什么导致了这一世和前一世不同，就像我上面写的这些一样，哈哈哈。或许比起漫无目的地在b站搜“神级小说推荐”，我应该自己总结一下爱看小说的共性，这里列举一下最近爱看的小说：《我的模拟长生路》、《战略级天使》、《贩罪》、《诡秘之主》和一些皇书。我【暂时】总结为梦到啥说啥的有时又有逻辑的装逼智斗文，看它们的时候会让我陷入一种自作聪明的奇妙状态，这就是这些书对于我的爽点吧。PS:我认为所有人看网络小说都是为了爽，不管是什么老书虫还是小白文爱好者，我对爽文没有任何偏见。

话说回来，我想我写这篇博客的行为也是由【一些事件】影响的，这里列举一下：

1.上午遇到了黑客黑售货机事件，感觉发现了只有我知道的辛秘

2.深受网络小说毒害，类似于看了奥特曼想要用变身器变身一样

3.在工位看了莫比乌斯的几篇博客后突然发觉自从建立博客后好久没有再发文章了，不想给自己以后定义3分钟热度的性格的时候提供佐证

4.进军币圈后亏损达到-100%，痛心疾首

5.看到室友哲哥在写纸质日记

……

我好像成为不了大人

以我目前粗浅的认知来分析程序员为什么总是自嘲为码农，工作大多数时间是配置和查询，有了AI以后本来要敲键盘的几行代码现在都变成Vibe Coding的模式。我不会写前端、忘记了博客更新部署的那些命令、忘了怎么写markdown yaml front matter……最后我还是写完并更新了这篇博客。前端有框架，命令可以查，或许每次重拾起博客都会遇到这些东西卡我一下，但其实都不如我写这篇文字来的时间长。

可能是最近太不干正事不爱学习了吧，目前我认为我需要摆脱【伪人】的状态。为什么这么讲呢，从几个例子来说明，首先无论是说话还是做事，自动地无限地进行自我反思，比如结束一段正常对话后不停复盘，试图找到一种无敌的底层说话逻辑应对所有的社交情况、在做事和说话前尽量找到一种讨好对方的方式、包装自己的真实意图来显示我是一个非常客观的人（不断地修改上面这一段话，并且在大部分情况下都不会说得太满，留有余地，想通过搞抽象来展示自己的真诚，而不是深入地对话交流）。另外，经常性地陷入宕机，包括说话冷场，思考过程中不经意地掉入空想，在这一过程结束后会后悔。最后也是最重要的，掉入了性恶论的怪圈，我自认为非常邪恶，有时候一些话在说出来之后就已经觉得那不是自己的本意，虚伪至极。即使面对亲人也是会像对陌生人一样尽量去讨好，而不是表达自己真实的感受。

有一个非常奇怪的事情，以至于我怀疑我被夺舍了。就是我对我从小玩到大的一个朋友产生了疏离感，明明在以前都是一起玩得非常开心，现在见到他只会说一些奉承讨好的话，即使是碰杯都要低于别人，真是魔怔了。。。

与人相处真是太难了，要再建立新的亲密关系更是天方夜谭，想起小学不敢排队打饭的那种恐惧了。但是明明最近几年过的还挺不错的，应该是过得太顺胡思乱想吧，希望如此。

前言

故事要从一个平凡的早晨说起。上班路上，我想买瓶茶喝，走到无人售货机前，却惊讶地发现屏幕上赫然显示着——“Hello World”。作为一名 CS 门下的弟子，每次见到这几个字母，总会忍不住生出点莫名的情绪：有时是不屑，有时是那种【我懂别人不懂】的自我满足感。

于是我开始胡思乱想，甚至给这件小事套上了修仙文的框架。就好像在外历练多年，突然在某个角落又看到当年初学时的【聚气决】，一瞬间心境生变，对大道生出新的感悟。我的脑海里立刻浮现出一个画面：某位【绝代天骄】（天才黑客）黑掉了楼下的无人售货机，只为炫耀实力。

为什么会蹦出这样一个故事呢？大概可以这样解释：

  1. 理想的种子：小学时玩《造梦西游》，拜师学习所谓【异次元修改】，就埋下了要做黑客的念头。
  2. 环境使然：身处超级大宗门——信息黄泉 BUPT，出个黑客似乎也合理。
  3. 爱幻想：总喜欢脑补字母背后的故事，渴望日常突然掉进神秘事件，还幻想着发工资后一把在币圈回本。
  4. 事件触发：这一天比往常多了一点刺激，刚好触动了我。

最近我在看一本小说《我的模拟长生路》。主角的金手指是能无限次带着记忆回到某个时空锚点。作者经常解释为什么这一世会和前一世不同，就像我上面分析的这些一样。哈哈。或许比起漫无目的地在 B 站搜“神级小说推荐”，我更应该总结一下自己爱看的小说共性。

最近沉迷的几本：《我的模拟长生路》、《战略级天使》、《贩罪》、《诡秘之主》，还有一些皇书。我暂时的总结是：梦到啥说啥，但时不时又有逻辑的装逼智斗文。读的时候让我陷入一种自作聪明的奇妙状态，这大概就是所谓的“爽点”。PS：我觉得所有人看网文都是为了爽，不管是老书虫还是小白文，我对“爽文”一词没有任何偏见。

说回正题，我之所以会写下这篇博客，其实也有【事件链】在推动：

  1. 上午偶遇“黑客黑售货机”的小插曲，感觉自己捕捉到一条隐藏剧情。
  2. 长期深受网络小说毒害，仿佛看完奥特曼就想自己也能拿个变身器。
  3. 在工位翻到莫比乌斯的几篇博客，突然想起自己博客荒废已久，不想以后被人定性为“三分钟热度”。
  4. 币圈血亏 -100%，痛心疾首。
  5. 看到室友哲哥在认真写纸质日记，心里也有点触动。

我好像成为不了大人

以我目前的浅见来看，程序员自嘲“码农”并非没道理。毕竟大部分工作时间都花在配置、查询上。现在有了 AI，本来要手敲几行的代码，也能直接进入 Vibe Coding 模式。

我不会前端，忘了博客更新部署的命令，甚至连 markdown 的 yaml front matter 都一度想不起来……不过最终还是写完并发了这篇文章。前端有框架，命令可以查，每次重拾博客都会被这些小细节卡住，但相比之下，写文字的过程反而花了更久的时间。

或许是最近不学无术太散漫了，我越来越觉得自己处在【伪人】状态。为什么这么说呢？举几个例子：

  • 无论说话还是做事，总是自动开启无限复盘模式。正常对话结束后也要反思一遍，想构建一种“万能的底层逻辑”来应对社交。
  • 习惯在说话前预演，想找到一种讨好对方的表达方式。真实想法会被一层层修饰、抽象，假装客观，其实是极度缺乏交流的勇气。
  • 经常陷入“宕机”状态：冷场、发呆、走神，事后又后悔。
  • 更严重的是，我掉入了“性恶论”的怪圈。总觉得自己很虚伪，有些话一说出口就后悔，甚至怀疑那不是我的本意。哪怕面对亲人，我也会像对陌生人一样谨慎讨好，而不是坦率表达。

更奇怪的是，我甚至开始对从小玩到大的朋友产生疏离感。过去无话不谈，如今却只会说些奉承讨好的话。连碰杯时都要小心翼翼地低过别人，整个人就像被魔怔了一样。

和人相处真的太难了。要再建立新的亲密关系，更是难如登天。让我想起小学时，不敢排队打饭时那种恐惧。可矛盾的是，最近几年我的生活其实还算顺利，大概是过得太顺，所以才有空瞎想吧。希望真的是这样。
